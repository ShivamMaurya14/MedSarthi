# Multilingual Healthcare AI Voice Agent

This project sets up a real-time, multilingual healthcare AI voice agent using Python, FastAPI, Vapi.ai, Twilio, Sarvam AI, and Google Gemini.

## 🚀 Setup & Execution

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Configure Environment Variables
Copy the `.env.example` file to `.env` and fill in the required API keys and phone numbers:
```bash
cp .env.example .env
```

You'll need:
- **VAPI_API_KEY**: From your [Vapi Dashboard](https://dashboard.vapi.ai)
- **Twilio Credentials**: From your Twilio Console
- **Sarvam API Key**: For Speech-to-Text and Text-to-Speech
- **Gemini API Key**: For the Google Gemini `gemini-2.0-flash` model
- **Triage Nurse Phone**: The emergency handoff direct line

### 3. Run Your Backend Server
Start your FastAPI instance. If developing locally, you must expose this URL to the internet (e.g., using `ngrok`).

```bash
uvicorn main:app --reload --port 8000
```
In another terminal, start ngrok:
```bash
ngrok http 8000
```
**Important:** Update the `SERVER_URL` in your `.env` with the generated `ngrok.app` URL.

### 4. Create the Vapi Agent
Once the server is running and accessible externally, run the script to register your specialized healthcare voice agent, configure the models (Gemini + Sarvam + Guardrails), and inject your custom Server endpoints as Tools:
```bash
python vapi_setup.py
```

Save the displayed `Agent ID` for configuring your telephony provider in the next step.

## 📞 Connecting Twilio to Your Vapi AI Agent

To receive live calls on a real phone number, you need to map your Twilio Phone Number to the Vapi Agent you just created.

### Step-by-Step Instructions:

1. **Purchase a Twilio Phone Number**
   - Log into your [Twilio Console](https://console.twilio.com/).
   - Navigate to **Phone Numbers > Manage > Buy a number**.
   - Purchase an active phone number capable of Voice.

2. **Retrieve Your Inbound Webhook URL from Vapi**
   - When a user dials your Twilio number, Twilio needs to ping Vapi to initiate the AI call sequence.
   - For Vapi, you typically import your Twilio account directly in the Vapi Dashboard, OR point Twilio's webhook to the Vapi generic inbound route.
   - **Method A: Vapi Dashboard integration (Recommended):**
     1. Go to your [Vapi Dashboard -> Telephony](https://dashboard.vapi.ai/telephony).
     2. Click **Import Twilio Account**.
     3. Enter your `TWILIO_ACCOUNT_SID` and `TWILIO_AUTH_TOKEN`.
     4. Vapi will automatically import your Twilio numbers.
     5. Select your purchased Twilio number and map it to the **Assitant ID** you generated by running `vapi_setup.py`.
   - **Method B: Manual Webhook Configuration (If instructed):**
     1. Since the backend handles Vapi logic, you can point Twilio Voice webhooks to Vapi’s generic SIP/Inbound URL. The URL format is `https://api.vapi.ai/call/twilio/inbound`. 
     2. To map it to your specific agent natively, pass the Agent ID in the URL structure or configure it in Vapi directly.

3. **Test the Pipeline!**
   - Dial the Twilio number from your mobile device.
   - Wait to hear the greeting: *"Namaste. Please let me know how I can help you with your health today."*
   - Engage with the AI in Hindi/English, and attempt to act highly frustrated or mention severe "chest pain" to test the Handoff Tool (`handoff-to-human`), which automatically utilizes Vapi's server instruction to transfer the SIP call to the human nurse's line.
